# 虚拟输入实测与边界

`run.ps1 -Upstream` 使用 Android 35 的 API 桩编译触控覆盖层，在主机 JVM 上测试控制布局和按键解析。已通过 13 项检查，详见同目录的 `test-results.txt`。指定的上游样本固定提交及内容哈希，来自 [FCL 官方控制布局](https://github.com/FCL-Team/FoldCraftLauncher/blob/617ab175789c3f5436943892b6f53904e9404a99/FCL/src/main/assets/controllers/00000000.json)。这份测试文件不会打进 APK。

| 范围 | 当前行为 |
| --- | --- |
| FCL JSON | 识别 controllerVersion 21、可见分组中的普通按钮与方向盘、绝对 dp 或相对屏幕宽高尺寸、0–1000 位置、支持的键码和鼠标按钮。官方样本识别 12 个可执行控件，跳过 1 个不产生键码的控件 |
| 原文件处理 | 导入后保留完整 JSON。导出时保留未知字段，编辑只更新相应位置字段。应用的画布使用统一样式，不复现所有外观或 FCL 宏 |
| 输入 | 多指各自拥有所按下的键，组合键支持按序按下与逆序释放。支持按住、单击、双击、长按、按住连击、滑动相对鼠标、方向盘斜向移动，物理键盘和基础手柄按钮映射。取消、失焦或离开游戏时释放已按键 |
| 实例布局 | 拖动并保存写入当前实例的 controls-v21.json；取消编辑恢复先前位置。导入文件需用户确认替换。自动补键采用稳定标识避免重复，按当前布局寻找未占用区域 |
| 游戏绑定 | 从已生成的 options.txt 读取可识别的旧版 LWJGL2 数字或现代翻译键；允许按绑定名选择并添加，共用键位带提示。运行时游戏及模组注册表、尚未落盘的绑定、陀螺仪、完整控制宏、模拟摇杆轴映射未接入 |
| 场景 | 控制层有按抓取状态筛选 FCL 的 IN_GAME / MENU 控件的接口；只有游戏适配器上报时才能自动跟随场景 |

此记录不代表在所有 Android 机型、实体键盘和手柄上完成实测。
