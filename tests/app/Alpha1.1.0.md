# Alpha1.1.0 安装与界面回归

本次使用 Android 6.0（API 23）x86 模拟器和软件图形驱动。手机测试使用 480 × 800、160 dpi；平板布局测试使用同一模拟器的 800 × 1280、160 dpi 显示配置。物理平板、Android 15 的系统边距及高刷新率帧时间仍待实测。

旧主包来自仓库的 `dist/LumenCraft-Alpha1.0.0.apk`。Android 报告版本代码 2、UID 10055，冷启动进入 `dev.lumencraft.MainActivity`。用于覆盖的通用 Release APK 的 SHA-256 为 `89129ff08d83f669154c0282dc83899b1f1e5468c78de246bd8f9a7b48cbd199`。

使用 `adb install -r` 覆盖安装后，Android 报告 `versionName=Alpha1.1.0`、`versionCode=3`。升级前后的 UID 均为 10055，设备记录的首次安装时间均为 2026-11-27 06:25:18。

## 界面与交互

| 操作 | 核对结果 |
| --- | --- |
| 手机竖屏打开游戏页，点击资源，再从左边缘向右滑动 | 五个入口在底部同一行；资源页显示 Modrinth 搜索，返回后显示游戏启动入口。[480 × 800 截图](alpha110/portrait.png) |
| 依次进入服务端、联机、设置，展开和收起运行设置 | 出现本地服务端、陶瓦房间和相应设置内容。选浅色和深色后，主题选项显示对应值。关闭动画后使用系统返回键，回到先前的联机页。随后将主题设回跟随系统、动画设回自动。[深色设置页](alpha110/dark-settings.png) |
| 手机横屏打开游戏页 | 五个入口改为左侧一列，启动操作与实例列表在右侧并排显示。[800 × 480 截图](alpha110/landscape.png) |
| 同一设备切换至逻辑分辨率 1280 × 800 | UIAutomator 中启动按钮的水平范围为 180–720，实例列表标题从 736 开始。界面维持双栏。模拟器将该逻辑画面缩放到 800 × 480 的物理截图中。[平板宽度截图](alpha110/tablet.png) |

以上操作由 [adaptive.py](adaptive.py) 驱动。末次 UIAutomator 快照与四张截图均已核对。平板截图在最后一项坐标断言通过后生成，测试进程随后结束，设备恢复至默认 480 × 800、160 dpi。此次运行的进程退出码未单独留存。
