# 五个官方早期客户端的主机回归

Windows x64，Temurin OpenJDK 17.0.20.1，TinyCC x64 0.9.27。使用与 Android 客户端相同的桥、OSMesa 版本、原始游戏 JAR、帧与输入协议。每项均从新的工作目录启动，在游戏中移动视角、输入按键、保存世界、拆除一个方块，再关闭游戏。每项解压后的退出存档都只改变了一个方块字节。

| 游戏版本 | 实收帧数 | 采样帧不同 RGB 数 | 拆除写入存档 | 正常退出 |
| --- | ---: | ---: | --- | --- |
| rd-132211 | 156 | 206 | 通过 | 通过 |
| rd-132328 | 156 | 243 | 通过 | 通过 |
| rd-160052 | 156 | 388 | 通过 | 通过 |
| rd-161348 | 156 | 448 | 通过 | 通过 |
| rd-20090515 | 156 | 1202 | 通过 | 通过 |

rd-161348 和 rd-20090515 的官方元数据不同，发布的游戏 JAR 有相同的 SHA-1，本表仍逐版本独立运行。rd-132211 的证据直接位于本目录，其余结果位于对应 ID 的子目录。每组包含两个未修饰的 320 × 240 原始帧、原版游戏输出和机器可读测试结果。

Android 原生运行测试使用单独的 x86 / Android 6 / OpenJDK 8 环境，详见[设备侧测试记录](../classic-api23/RESULTS.md)。
