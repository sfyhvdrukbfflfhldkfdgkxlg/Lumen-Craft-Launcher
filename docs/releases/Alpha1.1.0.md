# 微光 LumenCraft Alpha1.1.0

陶瓦联机已经集成到主启动器。安装通用 APK 即可使用游戏、局域网发现、纯服务端和房间管理。原先安装了 Alpha1.0.0 主包的用户可直接覆盖升级。Android 最低版本为 6.0。

- 房主可分享普通陶瓦码，或选择一个客户端实例分享带环境的邀请。访客确认后，启动器按精确版本准备游戏、Fabric 或 Quilt、Modrinth 模组及必要前置。未知 JAR 会指出文件名，需要先解决才能分享环境。
- 手机竖屏使用底部导航，宽屏使用侧栏。设置提供浅色、深色、跟随系统和关闭动画选项。远古游戏画面保留横屏操作。
- GLES 2 兼容层新增凸多边形绘制，四边形索引缓冲可在同一上下文复用。

通用 APK 包含四种原生架构，也可单独下载 arm64-v8a、armeabi-v7a、x86 或 x86_64 版本。每个安装包的 SHA-256 位于同页的校验文件。

可进入世界的客户端范围仍是已适配的五个 RubyDung 版本。现代版本的文件准备、房间连接和实际进入游戏分别记录。设备、渲染和联机验证范围见仓库的 [测试报告](https://github.com/sfyhvdrukbfflfhldkfdgkxlg/Lumen-Craft-Launcher/blob/Alpha1.1.0/TEST-REPORT.md)。
